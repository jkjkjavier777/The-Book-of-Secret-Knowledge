#### **💻 Shell One-Liners**
```bash
# Find all files modified in the last 7 days
find / -type f -mtime -7

# Count the number of lines in all files in a directory
wc -l *

# Find and delete all empty files
find /path/to/dir -type f -empty -delete

# Replace all occurrences of a string in all files
find /path/to/dir -type f -exec sed -i 's/old_string/new_string/g' {} +

# Find all files larger than 100MB
find / -type f -size +100M

# List all files sorted by size
ls -lS

# Find all files containing a specific text
grep -r "search_text" /path/to/dir

# Count the number of files in a directory
ls | wc -l
```

#### **🎯 Shell Tricks**
```bash
# Run a command in the background and disown it
nohup command & disown

# Quickly create a backup of a file
cp file.txt file.txt.bak

# Monitor a log file in real-time
tail -f /var/log/syslog

# Find and kill a process by name
pkill -f process_name

# Run a command as another user
sudo -u username command

# Quickly navigate to the last directory you were in
cd -

# Create a shortcut for a long command
alias shortname='long command with options'

# Run a command with a timeout
timeout 10s command
```

#### **⚙️ Shell Functions**
```bash
# Create a directory and navigate into it
mkcd() { mkdir -p "$1" && cd "$1"; }

# Quickly create a file with content
touchf() { echo "$2" > "$1"; }

# List files with details, sorted by size
lsf() { ls -lhS "$1"; }

# Check disk usage
duf() { du -sh "$1" 2>/dev/null | sort -h; }

# Monitor CPU usage
cpu() { top -bn1 | grep "Cpu(s)"; }

# Check memory usage
mem() { free -h; }

# Check open ports
ports() { netstat -tulanp; }

# Ping a host with a count
pingc() { ping -c "$2" "$1"; }

# Download a file with progress
wgetp() { wget --show-progress "$1"; }
```

## 🧠 **System Architecture & Mechanics**

### **Reward Shaping Engine**
*"R' = R - P"*

The **Reward Shaping Engine** governs how knowledge is acquired, retained, and rewarded:
- **R (Reward)**: Base reward for contributions. Default: **12**.
- **P (Penalty)**: Cost of repetition or silence. Default: **-3** for repeats, **-1** for empty inputs.
- **R' (Net Reward)**: Final reward after penalties.

---

## 🤖 **Adaptive Alpha Engine (JVI)**

### **Overview**
JVI (J. Kimo’s Virtual Intelligence) is the **chatbot** that interacts with users, providing answers, guidance, and occasional chaos. Powered by:
- **Python (`bot.py`)**: Core logic for processing inputs and generating responses.
- **Node.js (`server.js`)**: Backend server for web requests.
- **`replies.json`**: Predefined responses for common queries.
- **`quotes.json`**: Collection of wisdom.

### **Features**
1. **Dynamic Responses**: Adapts replies based on user input.
2. **Reward System**: Uses **R' = R - P** to encourage meaningful interactions.
3. **Logging**: Tracks interactions in `bot_output.log`.

---

## 🎨 **Personalization**

Customize JVI’s personality and behavior:
1. **Edit `bot.json`**: Adjust rewards, response style, and bot personality.
2. **Expand `replies.json`**: Add predefined responses.
3. **Update `quotes.json`**: Add wisdom from J. Kimo or other sources.

---

## 🧠 **Memory & Learning**

The Book of Secret Knowledge **learns and evolves** with every interaction:
1. **Interaction Logging**: Logs user inputs and responses.
2. **History Tracking**: Penalizes repeats, rewards creativity.
3. **Dynamic Replies**: Improves responses over time.
